Use your personal API token from Todoist Settings → Integrations → Developer. Enter it here in your own browser, never in chat or a GitHub file. ORBIT keeps it for this browser tab session only; exports never contain the token.

Only connect a personal token to your own trusted ORBIT site. A standard OAuth sign-in is a future improvement.
